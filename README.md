# 无人机表演 2.0 · 节目编排

一个纯前端的无人机编队表演节目编排工具。在浏览器里拖拽时间轴、排布队形、设计灯光，导出成节目单 JSON，直接用于实际无人机表演的指令下发或离线预览。

## 功能特性

- **时间轴编排**：按时间顺序排布多个表演段落，精确控制每一拍的起落与变换。
- **队形设计**：在画布上布置无人机点位，自由拼出文字、图案、几何阵列等队形。
- **灯光控制**：为每架无人机指定 RGB 灯光颜色，配合队形变换营造视觉效果。
- **节目单导入 / 导出**：以 JSON 格式保存与载入整套节目，方便复用与二次编辑。
- **实时预览**：编排过程中即时查看队形与灯光效果，所见即所得。

## 技术栈

- 纯静态单文件：`index.html`（内联 HTML / CSS / JavaScript，无构建步骤、无依赖）。
- 节目数据：标准 JSON。

## 本地运行

无需安装任何环境，直接用浏览器打开即可：

```bash
# 方式一：双击 index.html
# 方式二：起一个本地静态服务器（推荐，避免个别浏览器对本地文件的限制）
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 节目单格式（简版）

```json
{
  "name": "示例节目",
  "duration": 180,
  "tracks": [
    { "time": 0,  "formation": "heart",  "color": [255, 80, 120] },
    { "time": 30, "formation": "text",   "color": [120, 200, 255] }
  ]
}
```

> 字段结构以此示例为准，可在工具内导出实际节目单查看完整格式。
